# 🚀 CryptoHack Learning Journey

This repository documents my personal learning journey, challenges, and code explorations while working through cryptographic problems on [CryptoHack.org](https://cryptohack.org/). It was created as part of a university project for the subject **Ethics, Computer Law, and Data Protection** at [IIT North American Private University](https://iit.tn/).

---

## 📚 Project Context

As part of the coursework for the subject:

> **Éthique, droit informatique et protection des données**  
> *(Ethics, Computer Law, and Data Protection)*


I decided to explore cryptographic challenges as a way to improve my skills in security, math, and programming, and to document this learning process in a structured and reproducible way.

I fully acknowledge and respect the rules set by the [CryptoHack](https://cryptohack.org/) platform:

> _"Each user signs that they agree not to share solutions or writeups on other websites. This is to avoid spoiling the challenges for other players. 🔒 **I am not sharing full solutions or writeups here.**  
This repository is strictly for **educational purposes only**.  
Each folder will include **my personal exploration scripts or tools** that helped me understand or approach a specific challenge — **not the final answer or walkthrough**.
